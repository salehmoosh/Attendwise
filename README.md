# AttendWise

A simple web app to track attendance for all your subjects.

**Live demo:** https://salehmoosh.github.io/attendwise/

## What it does
- Add any subjects you want
- Shows attendance % for each subject and overall
- Tells you how many classes you can skip, or must attend, to stay above your required %
- Present / Absent buttons to update after each class
- Saves your data in your browser

## Built with
HTML, CSS and JavaScript

## Why I made it
Every student needs to keep track of the attendance rule, so I built a simple tool for it.
